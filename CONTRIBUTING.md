# Contributing

Thanks for helping improve DistShip.

Before opening a pull request:

1. Keep changes focused and explain the user-facing behavior.
2. Run `go fmt ./...`, `go vet ./...`, and `go test ./...`.
3. Add or update tests when behavior changes.
4. Do not commit credentials, private keys, environment files, or personal deployment configuration.

Please use an issue to discuss changes to the configuration protocol, deployment safety model, or platform support before implementation.
